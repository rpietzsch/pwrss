Feeds

    Export your subscriptions from Feedly at feedly.com/i/opml and import the file here. Articles and read state stay on this device.

    Proxy

    Browsers can't fetch feeds or article pages from other sites directly (CORS), so Pwrss uses your own tiny Cloudflare Worker for feeds and Reader mode. See the README.

    Feedly account (optional)

    Only needed if you pick “Feedly account” as source. Feedly now restricts API access, so this may not be available for your account.

    Use an access token instead

    Appearance

    Bottom keeps buttons within thumb reach. Applies to phone and tablet layouts; wide desktop windows always show toolbars on top.

    Keyboard

    J/K next/prev · M read · S save · R reader · V open · U filter · T theme · Shift+A mark all · Shift+R refresh · Esc back

    Gestures

    Swipe an article right/left to toggle read or saved. Long-press for a quick preview. Swipe from the left edge to go back. Pull down to refresh.
